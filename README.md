
# Save and load report through the toolbar in Javascript Pivotview component
A quick-start project that demonstrates how to save and load reports in the Syncfusion Javascript Pivotview component using the toolbar.

# Project prerequisites
Make sure that you have the compatible versions of Visual Studio Code installed on your machine before starting to work on this project. It is also recommended to have a basic understanding of HTML, JavaScript, and the Syncfusion EJ2 components so you can easily explore and modify the sample if needed.

# How to run this application
To run this application, you first need to clone the [Save-and-load-report-through-the-toolbar-in-javascript-pivotview-component](https://github.com/SyncfusionExamples/save-and-load-report-through-the-toolbar-in-javascript-pivotview-component) repository and then open it in Visual Studio Code. After opening the project, simply run the index.html file in any modern web browser. Once launched, it will render the EJ2 pivot table control, allowing you to try out the save and load report functionality directly from the toolbar for a better hands-on experience.
